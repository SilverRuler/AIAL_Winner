## 🍽️ 1. 미식 배틀 & AI 맛 심사

### 식사 등록 및 검증 정책
- **간편 참여**: 별도 회원가입 없이 12인 중 본인 이름 단일 선택 (타임대별 1인 1회 등록 제한)
- **식사 타임대 (KST 기준)**:
  - 🌅 **아침**: `05:00 ~ 10:00`
  - ☀️ **점심**: `11:00 ~ 13:30`
  - 🌙 **저녁**: `17:00 ~ 22:00`
  - 휴식 시간대(`10:00~11:00`, `13:30~17:00`, `22:00~05:00`) 및 과거/미래 날짜 등록 자동 차단
- **사진 업로드 & 최적화**:
  - 드래그 & 드롭, 파일 첨부, **클립보드(`Ctrl+V`) 이미지 붙여넣기** 지원
  - 클라이언트 캔버스 기반 고화질 WebP 자동 압축
  - EXIF 메타데이터 기반 촬영 시각 및 원본 사진 검증 (스크린샷·재전송 이미지 차단, 관리자 로그인 시 우회 허용)
- **식사 등록 보상**: 식사 사진을 등록할 때마다 **UFO 뽑기권 5장** 자동 지급

### AI 비전 맛 심사 (`WIN` 선정)
- **평가 모델**: 비전 LLM (`mistralai/mistral-large-4-1t-a52b`)
- **자동 / 수동 심사**:
  - 각 타임대 종료 시각(`10:00`, `13:30`, `22:00` KST)에 자동 심사 수행
  - 관리자 로그인 시 UI에서 즉시 수동 심사 실행 가능
- **심사 방식**:
  - 음식의 비주얼·구도·정성·풍성함을 종합 평가해 100점 만점 점수와 한국어 심사평 작성
  - 멤버가 직접 입력한 재미있는 제목/코멘트에 대해 1줄 재치 있는 코멘트 반영 (미입력 기본 제목 `오늘의 한 끼`는 언급 제외)
  - 최고점 우승작에 황금빛 `👑 WINNER` 배지 부여
- **모델 상태 모니터링**: 상단 헬스체크 바를 통해 AI 심사 모델의 실시간 가동 상태 확인

### 커뮤니티 & 아카이브
- **게시글 반응**: **조회수 → 좋아요 → 댓글** 순으로 일관 표시
  - 좋아요: IP 기준 1회 중복 방지 및 토글 취소 지원
  - 댓글: 마스킹 IP 표기 및 어뷰징 방지용 접속 환경 정보(User-Agent) DB 기록
- **필터 & 통계**: 날짜별·타임대별·멤버별·점수대별 필터, 키워드 검색, 역대 최고 점수(`Best Score`), 최다 우승(`Best Winner`), 명예의 전당(`Leaderboard`) 제공

## 🕹️ 2. 3D UFO 브릿지 크레인 뽑기 (`/gacha`)

실제 오락실의 **UFO 캐쳐(2-Bar 하시와타시)** 방식을 `Three.js` + `cannon-es` 120Hz 물리 엔진으로 구현한 3D 미니게임입니다.

### 개별 6개 뽑기판 (1판 1상품)
상품 간 충돌 없이 원하는 상품에 집중 공략할 수 있도록 6종의 상품을 각각 독립된 뽑기판에 배치했습니다. 상단 **1~6번 탭** 또는 하단 **`[이전 뽑기]` / `[다음 뽑기]`** 버튼으로 전환할 수 있습니다.

| 번호 | 상품명 | 형태 / 특징 | 난이도 | 당첨 리워드 |
|---:|---|---|---|---:|
| 1 | **프리렌 박스 #1** | 가볍고 컴팩트한 입문용 피규어 박스 | 난이도 5 (보통) | `0.003 SOL` |
| 2 | **네즈코 박스 #2** | 표준 규격·무게의 정석 브릿지 박스 | 난이도 6 (중상) | `0.008 SOL` |
| 3 | **노엘 실바 박스 #3** | 두툼하고 길어 정밀 각도 공략이 필요한 박스 | 난이도 7 (어려움) | `0.01 SOL` |
| 4 | **레제 박스 #4** | 중앙 Bar 틈새 여유가 좁고 무거운 고난도 박스 | 난이도 8 (고난도) | `0.015 SOL` |
| 5 | **바니카 박스 #5** | 정사각형에 가까운 와이드 박스 (옆세우기·누르기 특화) | 난이도 6.5 (정사각) | `0.009 SOL` |
| 6 | **산드로네 쿠션 인형 #6** | 3D 입체 다이컷 쿠션 인형 (4파츠 복합 물리 콜라이더) | 난이도 6.5 (입체 인형) | `0.01 SOL` |

### 크레인 조작 · 시점 · 현실 물리
- **조작 방식**: `1단계 우측(→) 이동` → `2단계 안쪽(↑) 이동` → 자동 하강·집기·들어올리기 (화면 버튼 꾹 누르기 및 키보드 방향키/`WASD` 지원)
- **카메라 시점**:
  - 대기 상태에서 **정면뷰 / 항공뷰 / 우측뷰** 자유 전환 가능
  - 크레인 조작 시작 시 **정면뷰로 자동 고정** (단, 정면 **까치발 업/다운 `0°~45°`** 조절은 조작 중에도 가능)
- **현실 아케이드 물리**:
  - 반발 튀어오름을 억제한 120Hz 물리 서브스텝 적용으로 **지그시 눌러 Bar 사이에 밀어넣는 공략** 가능
  - 한쪽 집게가 상자에 걸려도 크레인 머리가 끝까지 하강하여 반대쪽 집게로 상자 옆/아래를 파고들어 비스듬히 들어올리거나 밀어내는 현실적 동작 구현
  - 크레인 이동/정지 시 와이어 진자 흔들림(관성 스웨이) 반영, 집게 힘 부족 미끄러짐 확률 10% 미만 조정
- **특수 연출 & 효과음**:
  - **초기 원위치(재정렬/리필) 세팅 상태**에서 상품 정중앙 근처를 들어올리면 **`⚖️ Balance Catch!`** 팝업 및 전용 효과음 재생 (초기 세팅 상태에서는 `극한 드르륵!` 미발동)
  - **초기 상태 이후** 중앙 빨간 Bar 근처(위/아래)에서 집게를 들어올리면 **`⚡ 극한 드르륵! ⚡`** 1초 팝업 및 전용 효과음 재생
- **동시성 제어 & 운영 스케줄**:
  - 뽑기판별 턴 락(25초 TTL + 8초 하트비트)으로 동시 조작 충돌 방지 및 실시간 좌표 동기화
  - 매일 **`10:30`, `14:00`, `23:00` (KST)** 정기 자동 재정렬 및 리필
  - 최근 UFO 뽑기 당첨 현황: 기본 최신 4건 노출 → `[더 보기]` 클릭 시 페이지당 10건 페이지네이션 지원

### 뽑기권 및 연속 뽑기 정책
- **뽑기권 획득**:
  - 식사 사진 등록 시 **5장** 자동 지급
  - 식사배틀 신청 가능 승점 **`1 WIN` → 뽑기권 5장** 교환 (신청 가능 잔여 WIN이 1 이상일 때만 허용, 마이너스 가불 차단)
  - UFO 뽑기 보유 SOL 잔고 **`0.001 SOL` → 뽑기권 1장** 즉시 교환 (식사배틀 리워드와 엄격 분리)
- **연속 뽑기 혜택 & 환불**:
  - **연속 5가챠 시 +1회 무료 보너스 (총 6회 연속)** 지급
  - 연속 뽑기 진행 도중 **조기 당첨(상품 획득)** 시 **남은 미사용 유료 뽑기권은 자동으로 정상 반환**되며 당첨 팝업에서 즉시 확인 가능

## 💰 3. Solana(SOL) 리워드 & 관리자 기능

### 리워드 분리 운영 정책
- **식사배틀 리워드**: 식사배틀 명예의 전당에서 신청 가능 `WIN` 누적 시 SOL 리워드 신청
- **UFO 뽑기 리워드**: 뽑기 당첨으로 적립된 SOL 잔고 내에서 **원하는 SOL 수량을 직접 입력**해 신청 (업비트 입금 시 **`0.02 SOL` 이상** 모아 신청 권장)
- **본인 확인 퀴즈**: 리워드 신청 전 멤버 전용 확인 퀴즈를 통과한 뒤 솔라나 지갑 주소를 제출
- **운영자 지갑 잔고 조회**: Solana 메인넷 RPC와 연동하여 운영자 지갑의 실시간 SOL 잔고 조회 및 수동 강제 새로고침 지원

### 관리자 전용 기능
- 관리자 인증 후 식사 게시글 수정/삭제, 메타데이터 검증 우회 등록, 수동 AI 심사 실행
- 식사배틀 및 UFO 뽑기 리워드 신청 건 상태 관리(승인/지급 완료) 및 오신청 건 **Revert(신청 취소·복구)** 기능
- 개별 뽑기판 **리필** 및 **재정렬**, 멤버별 뽑기권 지급/차감, 퀴즈 관리

## 🛠️ 기술 스택 (Tech Stack)

- **Frontend / Fullstack**: Next.js 16 (App Router, Turbopack), React 19, TypeScript 5, Tailwind CSS 4
- **3D & Physics**: Three.js, cannon-es, canvas-confetti
- **Image / Media**: exifr, HTML5 Canvas WebP Compression, Web Audio API
- **Database**: MongoDB (`mongodb` 공식 Node.js 드라이버)
- **AI Vision Evaluation**: NVIDIA NIM Vision LLM (`mistralai/mistral-large-4-1t-a52b`)
- **Blockchain**: Solana Mainnet RPC (운영자 트레저리 잔고 실시간 조회)

## ⚙️ 환경 변수 (Environment Variables)

프로젝트 루트의 `.env.local` 또는 배포 플랫폼 환경 변수에 아래 항목을 설정합니다. *(실제 키·비밀번호·토큰 값은 절대 저장소에 커밋하지 않습니다.)*

| 변수명 | 필수 | 설명 |
|---|---|---|
| `MONGODB_URI` | 필수 | MongoDB 연결 문자열 (`mongodb+srv://<user>:<password>@<cluster>/...`) |
| `MONGODB_DB_NAME` | 선택 | MongoDB 데이터베이스 이름 (기본값: `aial_winner`) |
| `ADMIN_ID` | 필수 | 관리자 로그인 아이디 |
| `ADMIN_PW` | 필수 | 관리자 로그인 비밀번호 |
| `LLM_API_URL` | 필수 | 비전 LLM API 엔드포인트 URL |
| `LLM_MODEL` | 필수 | 식사 심사 비전 모델명 (예: `mistralai/mistral-large-4-1t-a52b`) |
| `LLM_API_KEY` | 필수 | 비전 LLM API 인증 키 |
| `SOLANA_TREASURY_ADDRESS` | 선택 | 운영자 리워드 지갑 공개 주소 (잔고 조회용) |
| `SOLANA_RPC_URL` | 선택 | Solana 메인넷 RPC URL |
| `TELEGRAM_BOT_TOKEN` | 선택 | 당첨 알림 및 운영용 텔레그램 봇 토큰 |
| `TELEGRAM_CHAT_ID` | 선택 | 알림 수신 텔레그램 채팅 ID |
| `TELEGRAM_WEBHOOK_SECRET` | 선택 | 텔레그램 웹훅 검증용 시크릿 토큰 |
