### 주요 기능 & 물리 특징
- **3D 인형 5종 클래식 인형뽑기**: 같은 3D 인형 **150개**를 바닥부터 높은 ㄱ자 외벽(`1.55m`)까지 7단 산더미로 가득 배치하고, **상·하·좌·우 4방향 자유 조준 + `[뽑기]` 버튼**과 타원형 메탈 헤드 + 얇은 스틸 4방향 집게(잡는힘/유지힘 `5 N·m`)로 인형을 집어 올린 상태를 유지하며 **좌측 하단(크레인 초기 위치) WIN 구멍** 위까지 운반한 뒤 집게를 벌려 낙하시키면 당첨됩니다.
- **13종 뽑기판별 고유 물리 프로필 (`MACHINE_PROFILES`)**: `#1 페른`을 기본값으로 두고 나머지 12개 기계마다 4-Bar 간격·높이, 크레인 헤드 크기, 집게 길이/두께, 닫힘·유지 토크, 실리콘 팁 마찰을 모두 다르게 설정했습니다.
- **현실 아케이드 물리 & 연출**: 연장된 `<>` 마름모 집게 암, 상단 정지 후 완전 개방 수직 낙하, **실시간 관전(LIVE)**, 특수 연출(`뽑기 시작!`, `Balance Catch!`, `극한 드르륵!`, `아슬 아슬!`, `당첨!`).
- **편의 UI & 운영**:
  - 상단 좌측 **`[선택]`**, **`[랜덤]`**, **`[관전]`** 빠른 이동 버튼 및 가로 스크롤(`◀`/`▶`·마우스 휠) 1~13번 탭

  - 데스크톱 뽑기 시작 시 브라우저 스크롤 간섭을 차단하는 **확대 집중 모드** 자동 활성화

## 🎲 3. 실시간 미니게임 (`Guessing-game` · Port 4500)

매일 **`14:00 ~ 14:03` (KST)** 입장 대기 후 진행되는 실시간 동시접속 미니게임(관리자 게릴라 오픈 가능)으로, 우승자에게 **뽑기권 +5장**을 즉시 지급합니다.
- **1명 참여**: 게임 없이 **자동 우승**
- **2명 참여**: **가위바위보(✌️/✊/✋)** 1:1 대결로 자동 전환 (비길 경우 최대 3회 데스매치, 3회 무승부 시 승자 없음)
- **3명 이상**: 30초 내 `1~9` 중 중복되지 않은 **가장 낮은 숫자**를 고른 단독 1명 우승 (전원 중복 시 최대 3회 서든데스)
- **사운드 & 보안**: 마감 5초 카운트다운 음성 + 진행 중 전용 BGM 재생, 1닉네임·1IP 중복 차단, 마감 후 이탈 시 즉시 탈락(OUT)

## 💰 4. Solana(SOL) 리워드 · 운영자 잔고 · 보안

- **리워드 분리 운영**: 식사배틀 리워드(`WIN`)와 UFO 뽑기 리워드(`SOL` 직접 입력 신청)를 분리 관리하며, 신청 전 본인 확인 퀴즈를 통과합니다.
- **운영자 잔고 & 예상 잔여 잔고**: Solana 메인넷 RPC와 실시간 원화 시세로 운영자 지갑 잔고 및 미신청/미지급 리워드 차감 후 **예상 잔여 잔고**를 표시합니다.
- **네트워크 보안 (Geo-Block)**: Nginx 레벨에서 **한국(KR) 및 Google 공식 IP 대역**만 접속을 허용하여 해외 비정상 트래픽을 원천 차단합니다 (주간 자동 IP 대역 갱신 cron 적용).

## 🛠️ 기술 스택 (Tech Stack)

- **Backend / Main Web**: Next.js 16 (App Router), React 19, TypeScript 5, Tailwind CSS 4, MongoDB
- **3D Physics Clients**: Vite + React + Three.js + **Rapier3D (Rust WASM)** / **Jolt Physics 1.1.2 (C++ WASM)**
- **Realtime Minigame**: Node.js + Socket.IO (`Guessing-game`)
- **AI / Blockchain / Infra**: NVIDIA NIM Vision LLM, Solana Mainnet RPC, Telegram Bot API, Nginx Geo-Block + PM2

## ⚙️ 환경 변수 (Environment Variables)

*(실제 키·비밀번호·토큰 값은 절대 저장소에 커밋하지 않습니다.)*

| 변수명 | 필수 | 설명 |
|---|---|---|
| `MONGODB_URI` | 필수 | MongoDB 연결 문자열 |
| `MONGODB_DB_NAME` | 선택 | MongoDB 데이터베이스 이름 (기본값: `aial_winner`) |

| `LLM_API_URL` / `LLM_MODEL` / `LLM_API_KEY` | 필수 | 비전 LLM API 엔드포인트 · 모델명 · 인증 키 |
